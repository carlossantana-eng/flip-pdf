Conectar ao repositório

Para enviar e editar catálogos por esta página, cole abaixo uma chave de acesso do GitHub (fine-grained token). Ela fica salva somente neste navegador — nunca é enviada para outro lugar além do próprio GitHub.

Como criar a chave (passo a passo)
  1. Abra github.com/settings/personal-access-tokens/new (entre na sua conta se pedir).
  2. Em Token name, escreva algo como estante-catalogos.
  3. Em Expiration, escolha a validade (ex.: 90 dias — quando vencer, crie outra e cole aqui de novo).
  4. Em Repository access, marque Only select repositories e escolha este repositório.
  5. Em Permissions → Repository permissions, defina Contents: Read and write. Nada mais é necessário.
  6. Clique em Generate token e copie o código que aparece (começa com github_pat_).
